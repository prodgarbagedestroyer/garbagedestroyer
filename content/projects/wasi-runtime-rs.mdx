## Overview

`wasi-runtime-rs` is a lightweight, embeddable WASI runtime that implements the [WASI preview2](https://github.com/WebAssembly/WASI/blob/main/preview2/README.md) specification. It's designed for server-side WebAssembly workloads where startup latency and memory overhead are critical.

## Architecture

The runtime is structured in three layers:

- **Module loader** — Parses Wasm binary modules, validates them, and sets up the linear memory model
- **WASI adapter** — Implements the preview2 system interface (filesystem, sockets, clocks, random)
- **Executor** — A stack-based interpreter with optional AOT compilation via Cranelift

## Benchmarks

Preliminary benchmarks against Wasmtime and Wasmer (single-threaded, cold start):

| Runtime       | Cold Start | Memory (idle) | Throughput |
| ------------- | ---------- | ------------- | ---------- |
| wasi-runtime-rs | 1.2ms    | 2.4 MB        | 8,200 req/s |
| Wasmtime      | 2.8ms      | 4.1 MB        | 9,100 req/s |
| Wasmer        | 3.4ms      | 5.6 MB        | 7,800 req/s |

## Usage

```rust
use wasi_runtime::{Engine, Module, WasiConfig};

let engine = Engine::new();
let module = Module::from_file("app.wasm")?;
let config = WasiConfig::default()
    .with_stdio()
    .with_preopened_dir("./data");

let instance = engine.instantiate(&module, config)?;
instance.run()?;
```
