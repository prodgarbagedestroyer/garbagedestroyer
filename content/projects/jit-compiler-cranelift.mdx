## Overview

`jit-compiler-cranelift` is a from-scratch JIT compiler that targets a minimal expression-based language. It's built as a learning resource — every pass is documented and deliberately unoptimized to expose the internals.

## The Language

A simple language supporting integers, booleans, arithmetic, conditionals, and function calls:

```
fn fib(n: i64) -> i64 {
    if n < 2 {
        return n;
    }
    return fib(n - 1) + fib(n - 2);
}

fn main() -> i64 {
    return fib(20);
}
```

## Pipeline

```
Source Text
    │
    ▼
┌─────────┐
│  Lexer  │  → Token stream (hand-written, no regex)
└─────────┘
    │
    ▼
┌─────────┐
│ Parser  │  → AST (recursive descent)
└─────────┘
    │
    ▼
┌─────────┐
│  Type   │  → Typed AST with i64, bool, fn types
│ Checker │
└─────────┘
    │
    ▼
┌─────────────┐
│ IR Builder  │  → Cranelift CLIF IR
└─────────────┘
    │
    ▼
┌──────────────┐
│ Codegen      │  → x86-64 machine code (Cranelift backend)
│ (JIT compile)│
└──────────────┘
    │
    ▼
┌──────────────┐
│  Execute     │  → Call compiled function via raw pointer
└──────────────┘
```

## Key Learnings

- Cranelift's IR is SSA-based — every value has a single definition
- EBBs (extended basic blocks) replace traditional basic blocks
- The JIT boundary requires careful ABI handling (System V calling convention)
- Register allocation is handled entirely by Cranelift — we never touch physical registers

## Usage

```bash
cargo run -- compile examples/fibonacci.lang
# Output: fib(20) = 6765
# Compilation: 0.4ms | Execution: 1.8μs
```
