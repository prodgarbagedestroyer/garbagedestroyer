## Overview

Builds identical HTTP servers across four languages, comparing image sizes with different base strategies: scratch, Alpine, distroless, and slim variants.

## Results (compressed size, MB)

| Stack | Scratch | Alpine | Distroless |
|---|---|---|---|
| Rust (musl) | 8.4MB | 10.2MB | — |
| Go | 6.1MB | 12.8MB | 8.3MB |
| Node.js | — | 118MB | 92MB |
| Python | — | 52MB | 46MB |

## Usage

```bash
docker buildx build --platform linux/amd64 -f Dockerfile.scratch .
docker images --format "{{.Size}}"
```
